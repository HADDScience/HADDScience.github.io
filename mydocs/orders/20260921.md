## 목록이 화면 밖으로 나간 이유

`ul.grid` 안의 `li` 는 그리드 항목이라 최소 너비가 `auto` 다. `li` 의 최소 너비는 그 안의
flex 줄의 min-content 인데, 제목 `<p>` 가 `truncate`(=`white-space: nowrap`)라 **제목 한 줄
전체 너비**가 그대로 최소 너비가 된다. 제목 안쪽 `<button>` 의 `min-w-0` 은 flex 레이아웃에서
줄여 주기는 해도 min-content 계산에는 쓰이지 않는다. 그래서 긴 제목 한 건이 목록 전체를
칸 밖으로 밀어낸다 — 한 건만 길어도 모든 줄이 같이 넓어진다(그리드 칸을 공유한다).

`li` 에 `min-w-0` 을 주면 칸 너비까지 줄어들고, 그 안에서 제목이 원래 의도대로 말줄임된다.
같은 구조가 편집기 상단 바(`post-editor` · `deck-editor`)에도 있어 함께 고쳤다 — 제목이 길면
sticky 바가 화면 밖으로 나간다.

실측(뷰포트 1700px · 컨테이너 1104px, Omnis API 를 목킹한 Playwright):

```
고치기 전:  ul 1104  li 1341  → 237px 초과
고친 뒤:    ul 1104  li 1104  → 초과 없음, 긴 제목만 말줄임
```

품질 게이트 `pnpm typecheck && pnpm lint && pnpm build` 통과(exit 0).
