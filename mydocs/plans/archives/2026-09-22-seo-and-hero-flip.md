# 2026-09-22 — 검색 노출(구글·네이버)과 히어로 플립 그리드

작업지시 (정우창, 2026-09-22):

1. 「하드사이언스 / haddscience / 오가노이드 / 생체소재」로 구글·네이버에서 찾아지게 한다.
2. 히어로 배경 콜라주를 **수상 사진**으로 바꾸고 시안을 여러 개 만든다.
3. 그 이미지가 **플립되며 2×3 으로 로테이션**되게 한다.

시안은 네 개(A 깊은 블러 · B 얕은 블러 · C 네이비 듀오톤 · D 수상+활동 혼합)를 구워
브라우저에서 비교했고 **B 를 채택**했다(2026-09-22). 검색엔진 소유확인 코드는 아직 없어
환경변수 자리만 만들고 절차를 문서로 남긴다. 화면 카피는 사실 범위에서 손대도 좋다는 승인을 받았다.

## 문제 1 — 그 검색어로 잡힐 근거가 사이트에 없다

`content/ko.ts` 전체에 **「오가노이드」와 「생체소재」가 한 번도 나오지 않는다**(2026-09-22 실측:
`grep -ril 오가노이드 content` → 기사 JSON 에만 있음). 메타 설명도 "자연유래 폴리핵산 젤 기술을
기반으로 3D 세포배양 소재 ADDGEL과 LiVEGEL을 개발합니다" 한 줄이라 그 단어가 없다.
검색엔진이 잡을 근거가 본문에도 메타에도 없으니, 등록만 해서는 순위가 생기지 않는다.

그 밖에 빠져 있는 것:

| 빠진 것 | 결과 |
|---|---|
| `metadataBase` · 페이지별 canonical | 상대 OG 경로가 절대 주소로 펴지지 않고, `/ko/...`·`/en/...` 가 중복 콘텐츠로 경쟁한다 |
| hreflang 이 페이지별이 아님 | 레이아웃이 모든 페이지에 `/ko`·`/en` 루트만 가리킨다 — 하위 페이지의 언어 짝이 틀린다 |
| OG 이미지 | 공유·검색 결과 카드에 그림이 없다. 카카오톡 공유도 마찬가지 |
| 구조화 데이터(JSON-LD) | 구글이 회사명·로고·사업장·수상을 사실로 읽을 근거가 없다 |
| 네이버 소유확인 · RSS | 네이버는 서치어드바이저 등록 + 사이트맵·RSS 수집이 사실상 전제다 |

## 문제 2 — 히어로 배경이 회사의 성과를 말하지 않는다

지금 배경은 활동 사진 6장을 한 장으로 합친 콜라주다(`public/hero/collage-*.webp`,
밝기 0.42 · 블러 18). 사진이 무엇인지 알아볼 수 없어 "자사 기록"이라는 성격이 전달되지 않는다.
2025 창업인큐베이팅 경진대회 **중소벤처기업부 장관상 대상**을 비롯한 수상 기록이 NAS 에 있는데
사이트 어디에도 쓰이지 않는다.

## 결정

| 결정 | 선택 | 버린 안 |
|---|---|---|
| 배경 구성 | 셀 6칸 × 사진 3장 = **18장을 굽고 칸마다 번갈아 보여준다** | 콜라주 한 장 교체 — 요청한 로테이션이 불가능 |
| 격자 | 데스크톱 3열×2행 / 모바일 2열×3행 (**둘 다 여섯 칸**) | 어디서나 2열×3행 — 와이드에서 세로로 긴 칸이 되어 사진이 잘린다 |
| 전환 | `rotateX(180deg)` 플립, 900ms, `cubic-bezier(.2,.6,.2,1)` | 페이드 — 요청이 "플립" |
| 리듬 | 2.6초마다 **한 칸만** 뒤집는다 (한 칸은 약 15.6초마다 바뀜) | 여섯 칸 동시 전환 — 배경이 화면을 빼앗는다 |
| 톤 | 시안 B — 블러 6 · 밝기 0.5 · 네이비 스크림 0.30 | A(블러 18) 는 장면이 안 읽히고, C 듀오톤은 현장감이 사라진다 |
| 접근성 | `prefers-reduced-motion` 이면 플립을 아예 걸지 않는다(첫 장 고정) | 느리게만 — 전정기관 자극은 속도가 아니라 회전 자체다 |
| 사진 경로 | 산출물만 `public/hero/tiles/` 에 커밋, 원본 경로는 `scripts/hero-tiles-sources.txt`(레포에만) | `public/` 에 목록 — 배포 사이트로 NAS 경로가 노출된다 |
| 키워드 | 메타 + **화면 카피에도** 오가노이드·생체소재·ECM 을 넣는다 | 메타만 — 본문에 근거가 없으면 순위가 생기지 않는다 |
| 소유확인 | 환경변수 두 개(`GOOGLE_SITE_VERIFICATION`·`NAVER_SITE_VERIFICATION`) | 코드를 소스에 박기 — 값이 바뀌면 배포를 다시 해야 하고, 저장소에 남는다 |

### 디자인시스템에서 벗어나는 두 가지 (의도)

- **사진 배경 금지** — 히어로 한 곳에 한해 이미 확장돼 있다(2026-08-12). 이번에도 그 한 곳뿐이다.
- **자동 재생 캐러셀 금지** — 캐러셀은 *읽을 내용*을 자동으로 바꿔 놓치게 만든다. 여기서 바뀌는 것은
  배경 텍스처뿐이고 h1·버튼은 고정이다. 그래도 규칙에서 벗어난 것이 맞으므로 README 에 남긴다.

### 사진에 대하여

시상식 사진에는 **타사 수상자와 기관 관계자가 함께 찍혀 있다.** 채택한 B 는 블러 6 이라
얼굴 윤곽이 남는다. 자사 직원이 아닌 사람이 식별될 수 있으므로, 대외 공개 전에 사용 가능 여부를
한 번 확인하는 편이 안전하다 — 판단이 서지 않으면 얼굴이 작게 잡힌 컷만 남기거나 시안 A 로 내린다.

## 이 계획이 하지 않는 것

- **순위를 약속하지 않는다.** 색인에 들어가는 것과 상위에 뜨는 것은 다르다. 「하드사이언스」는
  동명 회사·제품이 여럿이고, 「오가노이드」·「생체소재」는 대학·정부기관 문서가 상위를 잡고 있다.
  여기서 하는 일은 *잡힐 근거를 만드는 것*까지다.
- **네이버 블로그·뉴스 노출.** 네이버는 자사 문서(블로그·카페·뉴스)를 우선한다. 웹사이트 등록만으로는
  「하드사이언스」 검색 첫 화면에 들어가기 어렵다 — 필요하면 네이버 쪽 채널 운영이 따로 필요하다.
- **광고.** 검색광고는 이 작업 밖이다.
