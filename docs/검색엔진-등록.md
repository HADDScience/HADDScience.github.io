# 검색엔진 등록 안내 (구글 · 네이버)

haddscience.com 을 구글과 네이버가 찾아가게 만드는 절차입니다. 개발 지식이 없어도 됩니다.
한 번만 해 두면 그 뒤로는 새 기사가 올라올 때마다 자동으로 알려집니다.

필요한 것: **구글 계정**, **네이버 계정**, **Vercel 계정**(사이트를 배포하는 곳) 접근 권한.
Vercel 권한이 없으면 개발 담당자에게 3번 단계만 부탁하면 됩니다.

걸리는 시간: 각 30분 정도. 다만 **검색 결과에 실제로 나오기까지는 보통 며칠, 길면 2~3주**
걸립니다. 등록은 "와서 보라"는 신청이고, 언제 볼지는 검색엔진이 정합니다.

---

## 전체 흐름

두 검색엔진 모두 순서가 같습니다.

```
1. 사이트를 등록한다
2. "이 사이트가 정말 당신 것인가" 를 확인받는다  ← 확인 코드를 사이트에 심는 단계
3. 사이트맵(글 목록)을 제출한다
4. 며칠 기다린다
```

2번의 **확인 코드**는 검색엔진이 주는 긴 영문/숫자 문자열입니다. 이것을 사이트에
심어야 하는데, 우리 사이트는 코드를 소스에 박지 않고 **환경변수**로 받습니다.
값이 바뀌어도 코드를 고칠 필요가 없고, 저장소에 남지도 않기 때문입니다.

| 검색엔진 | 환경변수 이름 |
|---|---|
| 구글 서치콘솔 | `GOOGLE_SITE_VERIFICATION` |
| 네이버 서치어드바이저 | `NAVER_SITE_VERIFICATION` |

---

## 1. 구글 서치콘솔

### 1-1. 속성 추가

https://search.google.com/search-console 에 구글 계정으로 들어갑니다.
왼쪽 위 **속성 검색 → 속성 추가**를 누르면 두 가지를 물어봅니다.

| 선택지 | 어떤 것인가 | 우리 선택 |
|---|---|---|
| **도메인** | `haddscience.com` 과 그 아래 모든 주소를 한 번에. **DNS 설정을 고쳐야** 확인된다 | 쓰지 않습니다 |
| **URL 접두어** | `https://haddscience.com` 하나만. HTML 태그로 확인할 수 있다 | **이쪽을 고릅니다** |

**URL 접두어**를 고르는 이유: 도메인 방식은 도메인을 산 곳(가비아 등)에 들어가 DNS
레코드를 추가해야 하는데, 잘못 건드리면 사이트나 회사 메일이 멈출 수 있습니다.
URL 접두어 방식은 사이트에 태그 한 줄만 넣으면 되고, 우리는 그 자리를 이미 만들어 뒀습니다.

오른쪽 **URL 접두어** 칸에 `https://haddscience.com` 을 넣고 **계속**.

### 1-2. 확인 코드 받기

소유권 확인 화면이 뜹니다. **기타 확인 방법 → HTML 태그**를 펼치면 이런 줄이 보입니다.

```html
<meta name="google-site-verification" content="AbCdEf1234...xyz" />
```

여기서 **`content="…"` 안의 문자열만** 복사합니다. `<meta …>` 전체가 아니라 따옴표
안쪽만입니다. (전체를 넣으면 확인에 실패합니다.)

이 창은 **닫지 말고 그대로 둡니다.** 3번까지 마친 뒤 이 화면의 **확인** 버튼을 눌러야 합니다.

### 1-3. Vercel 환경변수에 넣고 다시 배포

1. https://vercel.com 로그인 → 프로젝트 **haddscience**
2. 위쪽 **Settings** → 왼쪽 **Environment Variables**
3. 아래와 같이 넣고 **Save**

   | 칸 | 값 |
   |---|---|
   | Key | `GOOGLE_SITE_VERIFICATION` |
   | Value | 1-2 에서 복사한 문자열 |
   | Environments | **Production** 체크 (Preview·Development 는 필요 없습니다) |

4. **환경변수는 저장만으로 반영되지 않습니다.** 위쪽 **Deployments** 탭 → 맨 위 배포의
   오른쪽 `⋯` → **Redeploy** → **Redeploy** 를 눌러 다시 배포합니다. 2~3분 걸립니다.

> 제대로 들어갔는지 보는 법: 배포가 끝난 뒤 `https://haddscience.com` 에서 마우스
> 오른쪽 → **페이지 소스 보기**, `Ctrl+F`(맥은 `⌘F`)로 `google-site-verification` 을
> 찾습니다. 아까 그 문자열이 보이면 된 것입니다.

### 1-4. 소유확인

1-2 에서 열어 둔 서치콘솔 창으로 돌아가 **확인**을 누릅니다.
"소유권이 확인되었습니다" 가 뜨면 끝입니다.

실패하면 대개 둘 중 하나입니다 — 재배포를 안 했거나, `content=` 안쪽이 아니라
`<meta …>` 전체를 붙여 넣었거나.

### 1-5. 사이트맵 제출

서치콘솔 왼쪽 메뉴 **색인 생성 → Sitemaps**.
**새 사이트맵 추가** 칸에 `sitemap.xml` 만 적고 **제출**합니다.
(칸 앞에 `https://haddscience.com/` 이 이미 적혀 있습니다.)

상태가 **성공**으로 바뀌고 "발견된 URL" 에 숫자가 뜨면 된 것입니다. 이 숫자는 회사
소개·제품·기사를 모두 합친 수라 수백 건입니다.

## 2. 네이버 서치어드바이저

구글보다 네이버가 더 중요합니다. 국내에서 회사 이름을 검색하는 사람 대부분이 네이버를
씁니다. 그리고 네이버는 **등록하지 않으면 웹사이트를 거의 수집하지 않습니다.**

### 2-1. 사이트 등록

https://searchadvisor.naver.com 에 네이버 계정으로 로그인 →
**웹마스터 도구 → 사이트 관리 → 사이트 등록**.

칸에 `https://haddscience.com` 을 넣고 확인을 누릅니다.

### 2-2. 확인 코드 받기

**사이트 소유확인** 화면에서 **HTML 태그** 방식을 고릅니다. 구글과 같은 모양입니다.

```html
<meta name="naver-site-verification" content="1a2b3c4d...z9" />
```

역시 **`content="…"` 안쪽 문자열만** 복사합니다.

### 2-3. Vercel 환경변수 + 재배포

1-3 과 똑같이 하되 이름만 다릅니다.

| 칸 | 값 |
|---|---|
| Key | `NAVER_SITE_VERIFICATION` |
| Value | 2-2 에서 복사한 문자열 |
| Environments | **Production** |

저장한 뒤 **Redeploy**. (구글 코드도 같이 넣을 거라면 둘 다 저장하고 재배포는 한 번만 하면 됩니다.)

### 2-4. 소유확인

네이버 화면의 **소유확인** 버튼을 누릅니다.

### 2-5. 사이트맵과 RSS 제출

왼쪽 **요청** 메뉴에서 두 가지를 넣습니다.

| 메뉴 | 넣을 주소 |
|---|---|
| **사이트맵 제출** | `https://haddscience.com/sitemap.xml` |
| **RSS 제출** | `https://haddscience.com/feed.xml` |

RSS 는 최신 기사 30건을 담은 목록입니다. 네이버는 사이트맵보다 RSS 를 더 자주 들여다보므로,
새 기사가 빨리 잡히길 바란다면 이것도 꼭 넣습니다.

### 2-6. 수집 요청

**요청 → 웹 페이지 수집**에 `https://haddscience.com/ko/` 를 넣고 확인을 누릅니다.
"지금 와서 보라"는 신청입니다. 하루 몇 건까지만 되므로, 중요한 주소부터 넣습니다.

| 우선순위 | 주소 |
|---|---|
| 1 | `https://haddscience.com/ko/` |
| 2 | `https://haddscience.com/ko/about/` |
| 3 | `https://haddscience.com/ko/products/` |
| 4 | `https://haddscience.com/ko/news/` |

## 3. 잘 되고 있는지 보는 법

### 바로 확인할 수 있는 것

| 무엇 | 어떻게 | 성공이면 |
|---|---|---|
| 확인 코드가 들어갔는가 | 첫 화면 → 페이지 소스 보기 → `site-verification` 검색 | 코드 문자열이 보인다 |
| 사이트맵이 살아 있는가 | 주소창에 `https://haddscience.com/sitemap.xml` | 주소가 잔뜩 적힌 화면 |
| RSS 가 살아 있는가 | 주소창에 `https://haddscience.com/feed.xml` | 기사 제목이 적힌 화면 |
| 색인을 막고 있지 않은가 | 주소창에 `https://haddscience.com/robots.txt` | `Disallow: /admin` 만 있고 `Disallow: /` 는 **없어야** 한다 |

### 며칠 뒤에 확인하는 것

- **구글**: 서치콘솔 왼쪽 **색인 생성 → 페이지**. "색인이 생성됨" 숫자가 0 이 아니면 들어간 것입니다.
  검색창에 `site:haddscience.com` 을 넣어 봐도 됩니다 — 나오는 목록이 구글이 알고 있는 우리 페이지입니다.
- **네이버**: 서치어드바이저 **리포트 → 수집 현황**. 네이버 검색창에는 `site:haddscience.com` 대신
  회사 이름으로 직접 검색해 봅니다.

며칠이 지나도 0 이면 개발 담당자에게 `robots.txt` 와 재배포 여부를 확인해 달라고 하면 됩니다.

## 4. 주의

### `DEPLOY_TARGET=pages` 가 켜져 있으면 전부 막힙니다

컨펌용 배포에서 쓰는 설정입니다. 이 값이 켜져 있으면 사이트가 **모든 검색엔진에게
"나를 수집하지 마라"고 말합니다.** 사이트맵도 비고, RSS 도 빕니다.

Vercel → Settings → Environment Variables 에 `DEPLOY_TARGET` 이 **Production 에 있으면
지우고 재배포**해야 합니다. 확인은 `https://haddscience.com/robots.txt` 에서 하면 됩니다 —
`Disallow: /` 한 줄만 보인다면 이 상태입니다.

### 주소를 바꾸면 다시 해야 합니다

소유확인은 주소(`https://haddscience.com`) 단위입니다. `www.haddscience.com` 은 대표
주소로 자동 전달되므로 따로 등록하지 않습니다.

## 5. 검색어별로 무엇을 기대할 수 있는가

등록은 **찾아질 수 있는 상태**를 만드는 일입니다. 순위는 별개이고, 검색어마다 사정이 다릅니다.

| 검색어 | 전망 |
|---|---|
| **하드사이언스** | 회사 이름이라 등록 뒤 비교적 빨리 잡힙니다. 다만 같은 이름을 쓰는 다른 회사·상호·책 제목이 있어 첫 줄을 장담할 수는 없습니다 |
| **haddscience** | 이 철자를 쓰는 곳이 사실상 우리뿐이라 가장 먼저 잡힙니다 |
| **오가노이드** | 대학·병원·정부기관·언론 문서가 상위를 차지하고 있습니다. 회사 소개 페이지 하나로 그 위에 서기는 어렵습니다 |
| **생체소재** | 위와 같습니다. 학술 문서와 기관 페이지가 두껍습니다 |

「오가노이드」·「생체소재」처럼 경쟁이 두꺼운 검색어에서 자리를 얻으려면, 그 주제로
**읽을 것이 실제로 쌓여야** 합니다. 지금 우리가 한 일은 사이트에 그 말이 존재하고
검색엔진이 읽을 수 있게 만든 것까지입니다. 그다음은 기사·자료를 계속 올리는 일입니다.

네이버의 경우 하나 더 있습니다 — 네이버는 **자사 서비스(블로그·카페·포스트·뉴스)를
웹사이트보다 위에 놓습니다.** 「하드사이언스」 검색 첫 화면에 들어가려면 웹사이트 등록만으로는
부족하고, 네이버 블로그 같은 채널을 따로 운영하는 편이 빠릅니다. 그것은 이 문서 밖의 일입니다.

---

## 6. 새 기사를 올린 뒤에는?

아무것도 하지 않아도 됩니다. `/admin` 에서 기사를 저장하면 사이트맵과 RSS 에 자동으로
들어가고, 검색엔진이 다음에 들를 때 가져갑니다.

빨리 넣고 싶을 때만 네이버 **웹 페이지 수집** 에 그 기사 주소를 넣거나, 구글 서치콘솔
맨 위 검색창에 기사 주소를 넣고 **색인 생성 요청**을 누릅니다.
