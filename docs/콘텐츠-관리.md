# 콘텐츠 관리 안내

홈페이지의 뉴스 기사를 쓰고 고치는 방법입니다. 개발 지식이 없어도 됩니다.

관리 화면 주소: **https://haddscience.github.io/admin/**
(실도메인으로 옮긴 뒤에는 `https://haddscience.com/admin/`)

---

## 1. 로그인

**HADD 계정으로 로그인** 버튼을 누르면 업무 시스템(Omnis)의 로그인 화면으로 갔다가
돌아옵니다. 업무 시스템에 이미 로그인돼 있으면 화면이 잠깐 지나가고 바로 들어옵니다.

- 계정은 업무 시스템과 같습니다. 비밀번호를 잊었으면 거기서 바꾸세요.
- 한 번 로그인하면 8시간 동안 유지됩니다. 나갈 때는 우측 상단 **나가기**.
- 퇴사 처리된 계정은 다음 새로고침부터 들어올 수 없습니다.

기사를 저장하면 GitHub 커밋 작성자에 여러분의 이름이 남습니다. 누가 무엇을 고쳤는지
변경 이력에서 그대로 볼 수 있습니다.

---

## 2. 기사 쓰기

**새 기사** 버튼 → 아래를 채우고 **저장하고 반영**.

| 항목 | 설명 |
|---|---|
| 대표 이미지 | 뉴스 목록 카드에 보이는 사진. 반드시 필요합니다 |
| 날짜 | `2026.08.27` 형식 |
| 원문 링크 | 보도자료처럼 외부에 원문이 있을 때만. 기사 아래 출처 링크가 붙습니다 |
| 제목 · 요약 | 요약은 목록 카드와 검색 결과에 나오는 한두 문장 |
| 본문 | 아래 네 가지 블록을 쌓아 만듭니다 |

### 본문 블록

- **본문** — 문단. 줄바꿈은 그대로 유지됩니다
- **소제목** — 긴 글을 나눌 때
- **인용** — 인터뷰 발언이나 강조하고 싶은 문장
- **이미지** — 사진. *대체 텍스트*는 화면 낭독기와 검색엔진이 읽는 설명이니
  비워 두지 마세요

블록마다 오른쪽 위 화살표로 순서를 바꾸고 휴지통으로 지웁니다.
오른쪽 **미리보기**는 실제 기사 페이지와 같은 화면입니다.

사진은 올릴 때 브라우저가 자동으로 가로·세로 1600px 이내 webp 로 줄입니다.
원본을 그대로 올려도 됩니다.

## 2-1. 카드뉴스 만들기

인스타그램·블로그에 올리는 정사각형 카드뉴스를 관리 화면에서 만듭니다.
디자인(파란 격자 배경 · 흰 카드 · 알약 배지 · 서체)은 정해져 있고, 여러분은
카드 종류를 고르고 내용만 채웁니다. **Chrome 브라우저에서 작업해 주세요.**
다른 브라우저는 그림으로 굽는 단계가 불안정합니다.

**새 카드뉴스** 버튼 → 아래 순서로 진행합니다.

1. **제목 · 요약 · 날짜**를 채웁니다. 제목은 뉴스 목록과 기사 페이지에 보입니다.
   대표 이미지는 비워 두면 첫 카드(표지)가 자동으로 쓰입니다.
2. 왼쪽 **카드 목록**에서 카드를 고르거나 **카드 추가**로 새 카드를 넣습니다.
   처음에는 표지 · 기본 · 한마디 세 장이 들어 있습니다.
3. 가운데 칸에서 **내용을 채웁니다.** 카드 종류마다 칸이 다릅니다.
4. 오른쪽 **미리보기**로 확인합니다. 글이 카드를 넘치면 빨간 경고가 뜹니다 —
   문장을 줄이거나 사진 비율을 낮추세요.
5. **PNG 내려받기** — 인스타그램용 1080×1080 PNG 를 zip 으로 내려받습니다.
   **저장하고 반영** — 사이트 뉴스에 기사로 올라갑니다. 둘 다 해도 됩니다.

### 카드 종류

| 종류 | 언제 쓰나 |
|---|---|
| 표지 | 맨 앞 한 장. 로고 · 제목 · 버튼 |
| 기본 | 제목 · 사진 · 본문. 가장 많이 쓴다 |
| 사진 위 | 사진이 위를 꽉 채우고 아래에 글 |
| 세로 사진 | 상장 · 포스터처럼 세로로 긴 사진. "자르지 않음"을 고르면 통째로 들어간다 |
| 사진 전체 | 사진 위에 글. 강조 컷 |
| 글만 | 큰 문장 하나. 도입 · 전환 |
| 숫자 | 지표 1~3개를 크게 |
| 목록 | 항목 나열. 번호 · 불릿 · 이모지 |
| 한마디 | 인용 + 이름. 마지막 장 |

- 제목에 내용을 상징하는 이모지를 하나 붙이면(🎤 🧫 🔬 🚀) 원래 카드뉴스 톤과 맞습니다.
- 줄바꿈은 그대로 반영됩니다. 파란 볼드 강조는 `<b>이렇게</b>` 감싸 주세요.
- 사진은 고정된 비율 상자에 채워집니다. 인물이 잘리면 **초점**을 바꿔 보세요.
- 보통 6~9장이 알맞습니다. 표지 → 도입(글만) → 본문(기본·사진 위·숫자·목록 섞어서) → 한마디.

카드뉴스로 만든 글은 목록에 `카드뉴스 N장`으로 표시되고, 다시 열면 이미지가
아니라 원래 편집 화면이 열립니다. 고친 뒤 다시 저장하면 그림을 새로 굽습니다.

**영문판은 같은 그림을 씁니다.** 카드 안의 글자는 번역되지 않고, 제목과 요약만
자동 번역됩니다. 영문 카드가 따로 필요하면 English 탭에서 이미지 블록을 바꿔 주세요.

## 3. 영문판

**한국어로만 쓰면 됩니다.** 저장하면 배포 과정에서 영문이 자동으로 만들어집니다
(몇 분 걸립니다).

영문을 직접 손보고 싶으면 **English** 탭에서 고치세요. 한 번 직접 고친 영문은
자동 번역이 다시 덮어쓰지 않습니다.

**사진은 언어별로 따로 넣을 수 있습니다.** 카드뉴스처럼 그림 안에 한글이 박혀
있으면, English 탭에서 그 이미지 블록의 사진만 영문판으로 바꿔 주세요.

## 4. 반영 시간

저장 = GitHub 에 커밋. 그 뒤 자동 빌드가 돌아 **보통 3~5분 뒤** 사이트에
반영됩니다. 바로 안 보이면 잠시 뒤 새로고침하세요.

잘못 저장했다면 관리 화면 우측 상단 **변경 이력**에서 해당 커밋을 찾아
`Revert` 할 수 있습니다. 기록이 남으므로 되돌리는 것은 언제든 가능합니다.

## 5. 관리자를 위한 메모 (개발 담당자용)

- 기사 원본은 `content/data/news/<id>.json` 한 건에 한 파일. 모든 언어가
  그 안에 들어 있습니다.
- 목록 순서는 `content/data/news/order.json`.
- 사진은 `public/news/<id>/...`. 카드뉴스는 원본 사진이 `src-NN.webp`,
  구운 카드가 `card-NN.webp` 로 들어가고 덱 원본은 기사 JSON 의 `deck` 에 있습니다.
- 로그인은 Omnis SSO(`lib/omnis-auth.ts`). GitHub 호출은 Omnis 의 `/api/website/github`
  프록시를 거치고, GitHub 토큰은 Omnis(Vercel) 환경변수 `WEBSITE_GITHUB_TOKEN` 하나뿐입니다.
  이 토큰이 만료되면 저장이 전부 실패하므로 만료 전에 Vercel 에서 갈아 끼웁니다.
- 자동 번역은 `scripts/translate-posts.mjs`. GitHub Actions 안에서 돌며
  API 키는 저장소 시크릿 **`ANTHROPIC_API_KEY`** 에 있습니다.
  키가 없으면 번역만 건너뛰고 배포는 정상 진행됩니다.
- 번역 다시 돌리기: `ANTHROPIC_API_KEY=... node scripts/translate-posts.mjs --force`
- 지원 언어를 늘리려면 `content/index.ts` 의 `LANGS` 와
  `scripts/translate-posts.mjs` 의 `SOURCE_TO_TARGETS` 에 추가하고,
  `content/<lang>.ts` 사전을 만듭니다.
