# 콘텐츠 관리 안내

홈페이지의 뉴스 기사를 쓰고 고치는 방법입니다. 개발 지식이 없어도 됩니다.

관리 화면 주소: **https://haddscience.com/admin/**

---

## 1. 로그인

주소를 열면 **업무 시스템(Omnis)에 로그인돼 있는 경우 그대로 들어옵니다.** 화면이 한 번
깜빡이며 업무 시스템을 다녀오는데, 누를 것은 없습니다. 로그인돼 있지 않으면 업무 시스템의
로그인 화면이 뜨고, 로그인하면 관리 화면으로 돌아옵니다.

- 계정은 업무 시스템과 같습니다. 비밀번호를 잊었으면 거기서 바꾸세요.
- 한 번 로그인하면 8시간 동안 유지됩니다. 나갈 때는 우측 상단 **나가기**.
  (나간 뒤에는 자동으로 다시 들어가지 않습니다. 들어오려면 로그인 버튼을 누르세요.)
- 퇴사 처리된 계정은 다음 새로고침부터 들어올 수 없습니다.

기사를 저장하면 누가 언제 고쳤는지 업무 시스템에 남습니다.

## 2. 기사 쓰기

화면 맨 위 **뉴스 / 하드:라이브러리** 탭으로 어느 목록을 다룰지 고릅니다. 옆의 숫자는 그
목록의 글 수입니다. 새 글을 만들면 **지금 보고 있는 탭의 목록**에 들어갑니다.

**새 기사** 버튼 → 아래를 채우고 **저장하고 반영**.

| 항목 | 설명 |
|---|---|
| 대표 이미지 | 뉴스 목록 카드에 보이는 사진. 반드시 필요합니다 |
| 날짜 | `2026.08.27` 형식 |
| 원문 링크 | 보도자료처럼 외부에 원문이 있을 때만. 기사 아래 출처 링크가 붙습니다 |
| 제목 · 요약 | 요약은 목록 카드와 검색 결과에 나오는 한두 문장 |
| 본문 | 아래 네 가지 블록을 쌓아 만듭니다 |

### 본문 블록

- **본문** — 문단. 줄바꿈은 그대로 유지됩니다
- **소제목** — 긴 글을 나눌 때
- **인용** — 인터뷰 발언이나 강조하고 싶은 문장
- **이미지** — 사진. *대체 텍스트*는 화면 낭독기와 검색엔진이 읽는 설명이니
  비워 두지 마세요

블록마다 오른쪽 위 화살표로 순서를 바꾸고 휴지통으로 지웁니다.
오른쪽 **미리보기**는 실제 기사 페이지와 같은 화면입니다.

사진은 올릴 때 브라우저가 자동으로 가로·세로 1600px 이내 webp 로 줄입니다.
원본을 그대로 올려도 됩니다.

## 2-1. 카드뉴스 만들기

인스타그램·블로그에 올리는 정사각형 카드뉴스를 관리 화면에서 만듭니다.
디자인(파란 격자 배경 · 흰 카드 · 알약 배지 · 서체)은 정해져 있고, 여러분은
카드 종류를 고르고 내용만 채웁니다. **Chrome 브라우저에서 작업해 주세요.**
다른 브라우저는 그림으로 굽는 단계가 불안정합니다.

**새 카드뉴스** 버튼 → 아래 순서로 진행합니다.

1. **제목 · 요약 · 날짜**를 채웁니다. 제목은 뉴스 목록과 기사 페이지에 보입니다.
   대표 이미지는 비워 두면 첫 카드(표지)가 자동으로 쓰입니다.
2. 왼쪽 **카드 목록**에서 카드를 고르거나 **카드 추가**로 새 카드를 넣습니다.
   처음에는 표지 · 기본 · 한마디 세 장이 들어 있습니다.
3. 가운데 칸에서 **내용을 채웁니다.** 카드 종류마다 칸이 다릅니다.
4. 오른쪽 **미리보기**로 확인합니다. 글이 카드를 넘치면 빨간 경고가 뜹니다 —
   문장을 줄이거나 사진 비율을 낮추세요.
5. **PNG 내려받기** — 인스타그램용 1080×1080 PNG 를 zip 으로 내려받습니다.
   **저장하고 반영** — 사이트 뉴스에 기사로 올라갑니다. 둘 다 해도 됩니다.

### 카드 종류

| 종류 | 언제 쓰나 |
|---|---|
| 표지 | 맨 앞 한 장. 로고 · 제목 · 버튼 |
| 기본 | 제목 · 사진 · 본문. 가장 많이 쓴다 |
| 사진 위 | 사진이 위를 꽉 채우고 아래에 글 |
| 세로 사진 | 상장 · 포스터처럼 세로로 긴 사진. "자르지 않음"을 고르면 통째로 들어간다 |
| 사진 전체 | 사진 위에 글. 강조 컷 |
| 글만 | 큰 문장 하나. 도입 · 전환 |
| 숫자 | 지표 1~3개를 크게 |
| 목록 | 항목 나열. 번호 · 불릿 · 이모지 |
| 한마디 | 인용 + 이름. 마지막 장 |

- 제목에 내용을 상징하는 이모지를 하나 붙이면(🎤 🧫 🔬 🚀) 원래 카드뉴스 톤과 맞습니다.
- 줄바꿈은 그대로 반영됩니다. 파란 볼드 강조는 `<b>이렇게</b>` 감싸 주세요.
- 사진은 고정된 비율 상자에 채워집니다. 인물이 잘리면 **초점**을 바꿔 보세요.
- 보통 6~9장이 알맞습니다. 표지 → 도입(글만) → 본문(기본·사진 위·숫자·목록 섞어서) → 한마디.

카드뉴스로 만든 글은 목록에 `카드뉴스 N장`으로 표시되고, 다시 열면 이미지가
아니라 원래 편집 화면이 열립니다. 고친 뒤 다시 저장하면 그림을 새로 굽습니다.

**영문판은 같은 그림을 씁니다.** 카드 안의 글자는 번역되지 않고, 제목과 요약만
자동 번역됩니다. 영문 카드가 따로 필요하면 English 탭에서 이미지 블록을 바꿔 주세요.

## 2-2. 하드:라이브러리 글 쓰기

논문·기사 소개처럼 뉴스가 아닌 글은 **하드:라이브러리** 목록에 넣습니다. 쓰는 방법은
기사와 같습니다 — 탭을 **하드:라이브러리** 로 바꾸고 **새 라이브러리 글** 을 누르면
같은 편집기가 열립니다.

| 항목 | 라이브러리에서는 |
|---|---|
| 대표 이미지 | 목록 카드에 쓰입니다. 논문이면 그림 한 장을 골라 주세요 |
| 요약 | 한두 문장. 목록 카드에 보입니다 |
| 원문 링크 | 논문·기사 원문 주소. 글 아래 출처 링크가 붙습니다 |
| 본문 | 기사와 같은 블록. 링크가 여러 개면 **링크 목록** 블록을 씁니다 |

- 카드뉴스는 뉴스에서만 만듭니다(라이브러리 탭에는 그 버튼이 없습니다).
- 주소는 `haddscience.com/ko/library/<글번호>` 입니다. 목록은 한 쪽에 12건입니다.
- 목록을 잘못 골랐으면 편집기 위쪽 **목록** 에서 바꿔 저장하면 됩니다. 옮긴 글은
  새 목록 맨 앞으로 가고 주소도 바뀝니다.
- 영문은 기사와 똑같이 자동 번역됩니다. **이미지는 번역하지 않습니다** — 그림 안에
  한글이 있으면 영문 탭에서 그림을 따로 올려 주세요.

## 2-3. 사이트 통계 보기

목록 위 첫 번째 상자는 **사람들이 얼마나 들어왔는지**입니다. 오른쪽 위 **7일 / 30일 / 90일**
로 기간을 바꿉니다.

| 칸 | 뜻 |
|---|---|
| 오늘 방문자 | 오늘(한국 시간) 들어온 사람 수 |
| N일 방문자 | 그 기간에 들어온 사람 수. 날짜별 숫자를 더한 값이 **아닙니다** — 같은 사람이 여러 날 왔으면 그만큼 겹쳐 셉니다 |
| N일 조회 | 페이지를 연 횟수. "1명당 N쪽" 은 한 사람이 평균 몇 쪽을 봤는지입니다 |
| 모바일 | 휴대폰에서 본 비율 |

### 글마다 몇 번 읽혔나

아래 목록에서 **글 제목 오른쪽에 조회 수**가 붙습니다(`96회`). 그 기간에 한 번도 안 열린 글은
`–` 입니다. 숫자 위에 마우스를 올리면 방문자 수도 나옵니다.

검색창 옆 **많이 본 순** 을 누르면 목록이 조회 수 순서로 다시 섭니다. **이건 화면에서만입니다** —
홈페이지에 나가는 글 순서는 그대로고, 고정(HADD PICK)도 그대로입니다. **목록 순서** 를 누르면 돌아옵니다.

기간(7일/30일/90일)을 바꾸면 이 숫자도 같이 바뀝니다. 한국어 글과 영문 글은 한 글로 합쳐 셉니다.

그 아래 막대는 **날짜별 방문자**입니다. 막대에 마우스를 올리면 그날 숫자가 나옵니다.
**많이 본 페이지**는 주소 대신 글 제목으로 보여 주고, **유입 경로**는 어디를 거쳐 들어왔는지
(검색·SNS)입니다. 아무 데도 거치지 않고 바로 들어온 방문은 여기 나오지 않습니다.

### 알아 두실 것

- **2026년 9월 22일부터 셉니다.** 그전 방문 기록은 없습니다 — 아무것도 모으고 있지 않았습니다.
- 관리 화면(`/admin`)에서 돌아다니는 것은 세지 않습니다.
- 쿠키를 쓰지 않습니다. 대신 같은 사람이 **날짜가 바뀌면 다른 사람으로** 세고, 폰과 PC 로
  들어오면 2명으로 셉니다. 정확한 개인 추적 대신 동의 배너 없는 쪽을 택한 결과입니다.
- 검색엔진 로봇은 대부분 빠집니다. 숫자가 실제보다 작아 보일 수 있지만, 부풀려진 것보다 낫습니다.

## 2-4. 콘텐츠 현황 보기

목록 위에 지금 **보고 있는 탭**의 현황이 나옵니다. 탭을 바꾸면 숫자도 함께 바뀝니다.

| 칸 | 뜻 |
|---|---|
| 첫째 타일 | 그 탭의 글 수 (전체 몇 건 가운데인지도 같이) |
| 카드뉴스 | 카드뉴스로 만든 글 수와 카드 장수 |
| 번역 있음 | 영문 본문이 들어 있는 글 수 |
| 최근 12개월 | 이번 달까지 열두 달 동안 올린 글 수와 마지막 글 날짜 |

### 손볼 것

그 아래 알약 단추는 **손볼 거리**입니다. 숫자만 보여 주는 게 아니라, **누르면 목록이
그 글만 남습니다.** 한 번 더 누르거나 **필터 해제** 를 누르면 풀립니다.

| 단추 | 무엇을 하면 되나 |
|---|---|
| 번역 없음 | 영문 본문이 비어 있습니다. 한국어 본문을 채워 저장하면 자동 번역이 돕니다 |
| 본문 없음 | 본문이 통째로 없는 글(원문 링크만 있는 글)입니다 |
| 썸네일 없음 | 목록 카드에 보일 사진이 없습니다 |
| 요약 없음 | 목록과 검색 결과에 나올 한두 문장이 없습니다 |

0건이면 단추가 흐려지고 눌리지 않습니다 — 그 항목은 손볼 것이 없다는 뜻입니다.

맨 아래 막대는 **월별 발행 건수**(최근 12개월)입니다. 막대에 마우스를 올리면 그 달과
건수가 나옵니다.

## 2-4. 기사 고정하기 (HADD PICK)

밀고 싶은 기사를 목록 맨 위에 붙박아 두는 기능입니다. 날짜와 상관없이 맨 앞에 오고,
홈페이지 카드에 **파란 테두리와 `HADD PICK` 배지**가 붙습니다. 영문 페이지도 같습니다.

**쓰는 법** — 목록에서 그 기사 줄 오른쪽의 **압정 버튼**을 누릅니다. 켜지면 줄 테두리가
파래지고 `HADD PICK` 이 붙습니다. 풀려면 한 번 더 누릅니다.

- 몇 건이든 고정할 수 있고, 뉴스와 하드:라이브러리에서 따로 셉니다.
- **고정을 풀면 원래 날짜 자리로 돌아갑니다.** 순서를 옮기는 게 아니라 얹는 것이라서요.
- 여러 건을 고정하면 원래 순서대로 나란히 맨 앞에 옵니다.

고정을 너무 많이 쓰면 표시가 흔해져 눈에 띄지 않습니다. 정말 앞에 둘 것만 고르세요.

## 5. 관리자를 위한 메모 (개발 담당자용)

- 기사는 Omnis(업무 시스템)의 DB 에 있습니다. 테이블 `WebsitePost`, 사진은 NAS 의
  `website/<기사 id>/…`. API 는 Omnis 의 `/api/website/*` 이고 정본 문서는 Omnis 저장소의
  `mydocs/plans/2026-09-07-website-posts-db.md` 입니다.
- 이 저장소의 `content/data/news/` 와 `public/news/` 는 옛 자료입니다. 사이트가 더 이상
  읽지 않으며, 이식이 검증되면 지웁니다.
- 로그인은 Omnis SSO(`lib/omnis-auth.ts`). 저장은 `lib/admin-posts.ts` 가 사진을 먼저
  올리고 기사를 PUT 합니다. 카드뉴스 원본 덱은 기사의 `deck` 에 있습니다.
- 로그인 화면은 세션이 없으면 자동으로 Omnis 를 한 번 다녀옵니다(탭당 한 번,
  `hooks/use-admin-session.ts`). 두 세션이 서로 다른 오리진에 있어 생기는 일이며
  자세한 것은 `mydocs/tech/content-storage.md` 에 있습니다.
- 고정은 `WebsitePost.pinned` 이고 토글은 `PUT /api/website/posts/<id>/pin` 입니다.
  `position` 을 건드리지 않으므로 풀면 제자리로 돌아갑니다. 목록 정렬은 Omnis 가 합니다.
- 자동 번역은 Omnis 가 저장 시점에 Gemini 로 합니다. 실패하면 관리 화면에 경고가 뜨고,
